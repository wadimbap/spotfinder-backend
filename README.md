# SpotFinder Backend

API-first Spring Boot backend for SpotFinder.

## Overview

SpotFinder is a map-based platform for discovering, creating, reviewing and moderating outdoor and extreme sport spots.

This repository contains the backend application built with Spring Boot.

## Planned Features

- authentication and authorization
- user profile and roles
- spot categories
- create and view spots
- moderation workflow
- reviews and ratings
- favorites
- PostgreSQL persistence
- Flyway migrations
- Swagger / OpenAPI
- Docker deployment
- CI/CD pipeline

## Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Gradle
- Docker
